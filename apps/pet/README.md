# 咕咕 GuGu · 养成桌宠（/pet/）

养在 Ale OS（os-open 网页操作系统）里的原创桌宠养成游戏：对标 QQ 宠物的核心体验（喂食、洗澡、玩耍、打工、成长、生病与性格养成），形象 100% 原创（AI 生成身体部件 + 代码驱动程序动画）。

## 玩法（无 API 完整可玩）

- **领养**：三配色蛋（奶黄/薄荷/樱粉）+ 起名 + 啄壳孵化；**一句话 AI 定制**（可选，BYOK 图像 API 按描述生成专属形象）
- **五维状态**：饱食/清洁/心情/精力/健康随真实时间衰减，**离线也结算**（宽容设计：速率五折、最多按 12 小时计）
- **照顾动作**：喂食/洗澡/玩耍（带冷却），睡觉回精力
- **经济（M1）**：打工赚元宝（心情好有加成）、接点心小游戏得分兑换元宝与心情、随机事件捡元宝；商店 6 种道具买即用（食物/清洁/玩具/感冒药）
- **养成（M1）**：学习耗精力换成长值与文艺倾向
- **成长**：成长值推动 蛋 → 幼年 → 少年 → 成年（三配色 × 三阶段素材齐全）
- **性格**：互动历史累积 贪吃/活泼/文艺/淡定 倾向，影响台词风格
- **AI 对话（M2，BYOK）**：设置里配 OpenAI 兼容接口后可与咕咕聊天（携带体征/性格上下文），失败自动回退本地台词；无 API 全功能可玩
- **形象工坊（M2）**：官方配色切换 + 自定义单图皮肤（上传/URL/分享码导入导出，IndexedDB 存储）
- **生病**：又饿又脏会生病，照顾好会痊愈；休闲模式不死（经典模式死亡/纪念墙规划中）

## 技术要点

- Next.js 静态导出（`output: 'export'` + `APP_BASE_PATH=/pet`），React 19 + zustand + Tailwind 4
- 形象方案：**分层部件 + 程序动画**（不做逐帧 spritesheet）——身体/蛋由图像生成模型产出（无脸版），眼/喙/腮红为代码 SVG 叠加，可眨眼、啾啾嘴、变表情
- 素材生产：`tools/gen-assets.mjs`（仅开发期使用，读 `.env.local` 的 Key，**Key 禁止入库**）→ 批量出图 → 白底 flood-fill 抠图兜底 → 裁切缩放入库 `public/skins/gugu/`
- 台词库：状态 × 性格 × 语言三维索引（`src/lib/lines.ts`），M2 起 BYOK LLM 对话在其上叠加
- 存档：localStorage `ale-pet-save`（版本化，跨页面 storage 事件同步——为壳内挂件形态预留）

## 与 OS 的集成

- `scripts/build-all.mjs` + `scripts/compose.mjs` 接入构建（子路径 `/pet`）
- `apps/shell/src/config/apps.ts` 注册（应用商城/命令面板自动收录）
- `apps/shell/public/config*.json` 桌面图标（icons 数组 + pages[0].iconIds 两处）
- **桌面挂件（M3）**：`/pet/widget/` 透明页被壳侧 `PetWidget` 以可拖拽浮窗 iframe 加载——咕咕住进网页操作系统的桌面上；桌面角落 🐣 开关，应用全屏自动隐藏；与独立页同源共享存档（storage 事件 + tick 双写守卫）
